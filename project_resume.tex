\textbf{高并发点评系统（Java）} \hfill 2024.06 – 2024.12 \\
\textbf{项目描述}：设计并实现了一个类似大众点评的商户点评系统，支持用户登录、商户查询、优惠券秒杀、笔记发布、关注推送等核心功能。系统基于Spring Boot框架，采用Redis多级缓存和分布式锁技术，通过Kafka消息队列实现异步处理，在高并发场景下保证系统的高性能和高可用性。
\begin{itemize}
    \item \textbf{多级缓存架构}：构建基于Redis的多级缓存架构，实现商户信息的高效查询。通过缓存空对象解决缓存穿透问题，使用互斥锁机制（Mutex）解决缓存击穿问题，采用逻辑过期方案保护热点数据。设计CacheClient工具类封装缓存操作，支持泛型化的缓存穿透和缓存击穿解决方案，提升代码复用性。
    \item \textbf{分布式锁与秒杀优化}：实现基于Redisson的分布式锁机制，解决高并发秒杀场景下的库存超卖和一人一单问题。通过Lua脚本保证库存扣减和订单校验的原子性操作，将秒杀判断逻辑前置到Redis，减少数据库压力。设计基于时间戳和序列号的分布式ID生成器（RedisIdWorker），支持每秒生成数百万个唯一订单ID。
    \item \textbf{异步订单处理系统}：构建基于Kafka的异步订单处理系统，将秒杀下单流程解耦为秒杀预判和订单创建两个阶段。前端接口在Redis中完成秒杀资格校验后立即返回，订单创建异步通过Kafka消费者完成数据库写入。通过Kafka的消息持久化和消费者组机制保证订单不丢失，实现幂等性消费防止重复下单。该设计将接口响应时间从200ms降低到20ms，QPS提升10倍以上。
    \item \textbf{地理位置查询}：实现基于Redis GEO的商户地理位置功能，支持用户按距离查询附近商户。使用GeoHash算法实现高效的空间索引，提供按经纬度排序的商户列表，优化用户体验。
    \item \textbf{点赞排行榜}：设计基于Redis SortedSet的点赞排行榜功能，使用时间戳作为分数实现点赞时间排序。通过ZSet结构实现点赞和取消点赞的幂等性操作，支持按点赞时间查询TopN点赞用户。
    \item \textbf{Feed流系统与关注功能}：实现关注推送的Feed流系统，采用Push模式将用户发布的笔记推送到粉丝的收件箱（Redis ZSet）。使用滚动分页（ScrollResult）实现基于时间戳的Feed流查询，解决传统分页在实时数据场景下的重复和遗漏问题。通过Redis Set实现共同关注功能，使用Set交集运算快速查询两个用户的共同关注列表。
    \item \textbf{签到统计功能}：实现基于Redis Bitmap的用户签到统计功能，使用位图存储用户每日签到状态。通过BitField命令实现签到记录和连续签到天数统计，相比传统方案节省99\%的存储空间。支持按月查询签到记录和统计连续签到天数。
    \item \textbf{双拦截器认证机制}：采用拦截器（Interceptor）实现用户登录态校验和Token刷新机制。设计双拦截器架构：RefreshTokenInterceptor负责Token续期，LoginInterceptor负责权限校验，保证用户会话的持续性和安全性。使用ThreadLocal实现用户信息在请求生命周期内的线程安全传递。
\end{itemize}
\textbf{技术栈}：Java 17、Spring Boot 2.7、MySQL 8.0、Redis、Redisson、Kafka、MyBatis Plus、Lombok、Hutool、Docker、Nginx
